# 실행 시작

`AGENT_TASK.md`를 실행 지시서로 사용한다.

이번 권한은 로컬 분석·코드 보완·테스트·기록 전용 연결까지다. 추가 quota 소비 실험, 실제 자동 전환, 배포 권한은 포함하지 않는다. 실제 저장소나 로그가 없으면 동봉 구현에서 가능한 작업을 진행하고 미연결/미측정을 정확히 구분한다.

## 폴더

- `AGENT_TASK.md`: 이번 작업의 목적·허용 범위·세부 작업·완료 기준.
- `references/v1/`: 기존 참조 구현과 테스트. 실제 rollover 저장소는 아니다.
- `references/latest-review/`: 최근 재검토와 추가 검산 코드.
- `references/comparison/`: 앞선 공식 비교 검토.
- `references/claude-checks/`: Claude가 제공한 독립 계산 코드·당시 출력 원본.

검토서와 코드의 가격·quota 상수는 당시 가정/보고값이다. 현재 실측으로 무조건 취급하지 않는다. 첨부된 출력은 과거 실행 기록이며, 이 패키지를 만들면서 테스트를 새로 실행한 결과가 아니다. 실행 전 코드를 확인하고 테스트는 에이전트가 현재 환경에서 다시 수행한다.

문서와 코드의 상대 실행 경로는 원래 묶음과 다를 수 있다. 필요한 경우 모듈 경로를 명시해서 실행하며, 저장소의 기존 빌드 절차를 우선한다. `SHA256SUMS.json`은 이 전달 묶음의 파일 확인용이다.
