## 수행 순서

### 1. 자료 충분성부터 판정

각 분석 질문에 필요한 필드와 실제 존재하는 필드를 대응시켜라. 파일 수·대상 기간·유효 표본·제외 표본과 제외 사유를 기록하라.

각 항목은 다음 중 하나로 분류하라.

- 기존 자료로 결론 가능
- 기존 자료로 조건부 추정만 가능
- 기존 자료로 식별 불가능
- 측정 대상이 아니라 운영자가 정할 기준

단순히 “자료 부족”이라고 쓰지 마라. 어떤 필드나 대조가 없어 어떤 결론이 불가능한지 명시하라.

### 2. 최우선: 기존 운영 로그로 복귀 확률 q를 추정할 수 있는지 조사

- 분석 단위는 세션 전체가 아니라 유휴 구간이다. 유휴 시작과 **실제 사용자 복귀**를 구분할 근거부터 확인하라.
- 자동 continuation, goal 재개, 도구·자식 작업 완료, 실험용 입력, 에이전트의 자체 입력은 사용자 복귀로 세지 마라.
- 실험을 위한 강제 종료, rate-limit 대기, rollover, 작업 종료, 관측 중단을 구분하라. 구분할 수 없는 구간은 불확실 또는 제외로 표시하라.
- 로그가 끝났다는 이유로 영구 미복귀로 분류하지 마라. 작업 종료와 우측 검열(아직 복귀를 관측하지 못한 채 기록이 끝남)을 구별하라.
- 자료가 충분하면 5·30·60·120분 내 복귀 비율 또는 시간대별 복귀 분포 후보를 산출하라. 표본 수, 관측 기간, 검열, 세션·작업 유형별 편향, 불확실성을 함께 제시하라.
- 가능하면 시간 구간을 나눠 추정과 검증을 분리하라. 짧거나 편향된 표본을 “보정된 운영 예측”으로 승격하지 마라.
- 자료가 부족하면 부족한 최소 로그 항목과 **추가 모델 호출 없이 일상 사용 중 수집할 방법**을 제안하라. 수집 설정을 실제로 켜지는 마라.
- q=1 또는 q=0을 임의로 넣지 마라. 후보 추정값이 생겨도 운영 설정에는 주입하지 마라.

### 3. 기존 실험 데이터의 미확정 항목 재분석

q 분석과 독립적인 부분만 병렬화할 수 있다. 동일 파일을 여러 작업자가 수정하지 마라.

- **출력 계수·계기 지연:** 이미 수행한 지연 0/1 가설 비교와 산술 근거를 먼저 읽어라. 추가로 구분할 수 있는 것이 있는지 확인하되, 같은 데이터에 여러 모형이 맞으면 하나를 확정하지 마라. 사후 적합값을 측정 계수로 바꾸지 마라.
- **시스템·스킬 중복:** 기존 요청 캡처·프롬프트 구조·usage에서 내용 중복과 집계 중복을 구분하라. 텍스트가 중복됐다는 사실과 서버가 실제 청구한 quota 분담을 동일시하지 마라.
- **복원 비용·재설명 부담:** 저장된 응답과 단계별 usage를 분석하라. 오염된 2회차는 참고 분석으로 별도 표시하고, 기존의 깨끗한 비용 합산에 몰래 넣지 마라. 표본 한 개로 변동성이나 일반적 품질을 입증하지 마라.
- **기존 실제 작업의 품질·지연:** 관련 로그가 있다면 실패·재설명·복귀 지연을 조사하라. 선택하지 않은 정책의 실제 결과까지 관측한 것으로 취급하지 마라.
- **허용 지연·품질 저하:** 데이터로 정해지는 추정값과 운영자가 정할 허용치를 분리하라.

### 4. 가능할 때만 오프라인 정책 재생

기존 DP를 유지하라. 근거 있는 복귀 분포 후보가 만들어졌다면 `KEEP_WARM / PARK / LET_EXPIRE`를 계수 범위 양 끝과 주요 불확실성 아래에서 재생하라.

실측, 로그 추정, 미검증 보고값, 가정 시나리오를 섞어 표시하지 마라. 특히 추정 q를 사용한 계산은 실제 세 정책의 대조 실험이 아니다. 결론이 입력 범위에 따라 바뀌면 조건부 결과로 보고하라. 예측 자료가 없으면 그 사실을 명시하고 이 단계를 생략할 수 있다.

## 산출물과 종료 조건

분석 전용 작업트리에 다음을 남겨라.

- `.omo/evidence/idle-existing-data-analysis/`: 입력 목록·해시, 재현 스크립트·명령·출력, 제외 근거, 정리 영수증

새 분석 로직의 핵심 수치는 독립적인 소규모 계산 또는 다른 경로로 교차 확인하라. 원시 로그가 변하지 않았는지도 확인하라. 문구를 고정하는 테스트나 변경과 무관한 전체 테스트 재실행은 하지 마라.

보고서는 다음 순서로 작성하라.

1. 기존 자료로 새로 알아낸 것과 여전히 알 수 없는 것을 첫 문단에 명시한다.
2. `질문 | 자료·유효 표본 | 결과·범위 | 실측/추정/가정 구분 | 한계 | 추가 실측 필요 여부` 표를 제시한다.
3. q의 추정 가능 여부와 근거, 가능했다면 오프라인 정책 재생 결과를 설명한다.
4. 후속 항목을 `기존 자료로 완료 / 일상 관측만 필요 / 새 실측 필요 / 사용자 기준 결정`으로 나눈다.
5. 정말 새 실측이 필요하다면 질문, 최소 측정 설계, 예상 요청 수·비용 불확실성·대기 종류·필요 승인을 제안만 한다. 실행하거나 승인 답을 기다리며 작업을 붙잡지 마라.

**기존 자료로 확정 가능한 결과와 식별할 수 없는 이유가 근거로 분리되고, 재현 자료와 보고서가 완성되면 종료하라. 결론을 억지로 만들지도, 전체 유료 실험을 다시 돌리지도 마라.**
