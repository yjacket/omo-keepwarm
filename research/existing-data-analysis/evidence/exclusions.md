- 확장 자신이 보내는 `/rollover now`(`successor_found` 직후의 `command{verb:"now"}`) 29건은 사용자 입력으로 세지 않았다. 코드 근거는 `extension/rollover.ts`의 `tryRollover`에 있는 `pi.sendUserMessage("/rollover now")`다.
- 우측 검열(아직 복귀를 관측하지 못한 채 기록이 끝남)로 처리한 것은 셋이다. 이 구간들을 영구 미복귀로 바꾸지 않았다.
  - 자동 재개: goal 계속, 작업 완료, 모니터 알림. 14건이다.
  - 로그 끝: 4건이다.
  - 대화 기록 끝: 1건이다.
- 사용자가 세션을 닫거나 전환한 경우(`quit`/`new`/`resume`)는 23건이다. 뒤에 같은 세션이 다시 열리지 않은 경우만 경쟁 사건 "맥락 종료"로 셌다. 작업 완료의 증거는 아니다. 다시 열린 경우는 전환 뒤의 기록에서 계속 추적했다.
